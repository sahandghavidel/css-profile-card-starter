# CSS Profile Card Starter

Starter files for Sahand’s JavaScript King CSS profile card tutorial.

## Get started

1. Click **Code** → **Download ZIP** on this page.
2. Extract the ZIP and open the extracted folder in VS Code.
3. Open `index.html` in your browser to see the starter page.
4. Follow the tutorial to add your CSS in `style.css`.

Keep `index.html`, `starter.css`, `style.css`, and `sahand.png` in the same folder.
